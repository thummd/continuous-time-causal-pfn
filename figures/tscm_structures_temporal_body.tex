% Eight identification structures of dot-Identifiability-v1 as *temporal* SCMs,
% unrolled over two consecutive slices T-1 (pre-intervention) and T (intervened).
% Edge lists transcribed from dotime src/dotime/tscm_sampler.py with
% use_lagged_edges=True (the released-suite configuration):
%   bi_variate:            A->Y inst
%   observed_confounder:   X->A inst;              X(t-1)->Y(t) lag
%   back_door:             X->A, X->Y, A->Y inst;  X(t-1)->Y(t) lag
%   mediator:              M->Y inst;              A(t-1)->M(t) lag
%   front_door:            U->A, U->Y, A->M, M->Y inst; M(t-1)->Y(t) lag
%   confounder_mediator:   X->A, A->M, M->Y inst;  X(t-1)->Y(t) lag
%   instrumental_variable: U->A, U->Y, X->A, A->Y inst
%   unobserved_confounder: U->A, U->Y inst
% plus an autoregressive lag-1 self-loop on every variable.
% do(a_T) severs the incoming edges of a_T (drawn red dashed).
